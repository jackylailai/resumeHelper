# Samples

Test fixtures used by the smoke script and integration tests.

| File | Purpose |
|---|---|
| `sample_jd.txt` | A representative job description for FastAPI/Postgres roles. |
| `sample_resume.pdf` | **Not committed.** Drop your own (or any non-PII test) PDF here before running the smoke script. |
| `sample_resume.docx` | **Not committed.** Optional DOCX fixture. |

The PDF / DOCX files are intentionally excluded from version control because
they may contain personal information (`backend/storage/` is also git-ignored
for the same reason).
